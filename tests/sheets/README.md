# Sample sheets for the teaching-engine tests

| File | What it tests |
| :--- | :--- |
| `mumbai-leaders.pdf`, `mumbai-events.pdf` | Grade 8 revision sheets printed from a browser: every printed line is its own text block, bullets are drawn dots, a comparison table, practice questions with inline answers, a memory tip and a page footer. |
| `mumbai-personalities-flat.pdf` | The same layout with no colours or bold. |
| `lesson-subheadings.pdf` | Larger-font sub-headings, a "Term: meaning" list and questions numbered on one line. |
| `comparison-panels.pdf` | Two bullet lists side by side under short headings. |
| `compact-revision.pdf` | Facts separated by "•" and "|", and a question / working / answer table. |
| `equations.pdf` | Formulas and worked equations. |
| `missing-script-font.pdf` | Devanagari set in a font with no Devanagari letters, so the PDF's text layer is unreadable. |

The sheets were supplied as test material. The card tests check structure only; passing them says nothing about how well the cards teach.
